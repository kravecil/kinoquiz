# КиноКвиз

Браузерная игра для Яндекс Игр: угадай фильм по короткому описанию. Визуальный стиль — старый кинотеатр: бархатный зал, латунь, вывеска с лампочками, варианты ответа в виде бумажных билетов.

**Стек:** TypeScript (strict) · Preact + Signals · Vite · Vitest. Сервера нет — сохранения, покупки и рейтинг идут через SDK площадки.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты ядра, контента и локализации
npm run build      # проверка типов и контента + сборка в dist/
```

В режиме разработки игра работает на заглушке площадки (`LocalPlatform`): реклама, покупки и вход показываются как диалоги с пометкой MOCK. Параметры URL:

| Параметр | Что делает |
|---|---|
| `?lang=en` | язык, который «сообщает площадка» |
| `?auth=0` | игрок не авторизован (проверка приглашения войти) |
| `?ads=fail` | рекламу не досматривают (награда не выдаётся) |
| `?fast=1` | реклама и покупки без диалогов и задержек (для автотестов) |

## Как устроена игра

- **Марафон.** Вопросы идут подряд, сложность растёт (первые 5 — лёгкие, к 12-му открываются все уровни). Фильмы в сеансе не повторяются, а вопросы, которые игрок уже видел, показываются в последнюю очередь.
- **Сложность вопроса** = известность фильма (1–3) + уровень описания (лёгкое или абстрактное). Неверные варианты подбираются похожими: близкий жанр и годы, мультфильмы не смешиваются с игровым кино.
- **Очки:** база по сложности × бонус за скорость (до +50%) × множитель серии (до ×2) × штраф за подсказки.
- **Билеты** (жизни): 5 штук, ошибка стоит одного, +1 каждые 20 минут. Когда билеты кончились, сеанс можно один раз продолжить за рекламу или докупить билеты.
- **Жетоны** (мягкая валюта): за верные ответы, серии, ежедневный бонус и рекламу. Тратятся на подсказки.
- **Подсказки:** 50/50, год, жанр и страна, режиссёр, «второй шанс» (ошибка не сгорает), пропуск вопроса.

Весь баланс — в `src/core/config.ts`.

## Структура

```
src/
├── core/        # логика игры без DOM и SDK: подбор вопросов, марафон, очки, билеты, сохранения
├── platform/    # интерфейс площадки IPlatform и заглушка LocalPlatform
├── state/       # состояние на сигналах: сохранения, экономика, сеанс, касса, реклама, рейтинг
├── content/     # films.json (общие данные) + texts/<язык>.json (названия и описания)
├── i18n/        # словари интерфейса и реестр языков
├── audio/       # звуки, синтезированные через Web Audio
├── ui/          # экраны и компоненты Preact
└── styles/      # токены палитры, база, компоненты, экраны
tools/
└── validate-content.mjs   # проверка контента перед сборкой
```

Ядро (`core/`) не знает ни о браузере, ни о Яндексе. Поэтому оно покрыто тестами и может переехать на другую площадку: достаточно реализовать `IPlatform`.

## Контент

Описания написаны специально для игры. Тексты Кинопоиска, постеры и кадры не используются: это чужой контент.

**Добавить фильм:**
1. Запись в `src/content/films.json`: `id`, год, жанры, коды стран ISO, `popularity` (1 — знают все, 3 — для киноманов).
2. Тексты с тем же `id` в каждом `src/content/texts/<язык>.json`: название, режиссёр, два описания (лёгкое с зацепками и абстрактное) и варианты названия в `aliases`.
3. `npm run content:check` проверит, что тексты есть на всех языках, а в описаниях нет слов из названия.

## Локализация

Сейчас есть русский и английский. Язык берётся из площадки: для языков СНГ показывается русский, для остальных — английский. В настройках язык можно сменить вручную.

**Добавить язык:**
1. `src/i18n/locales/<код>.ts` — словарь интерфейса. Можно частичный: недостающие строки возьмутся из fallback-языка.
2. `src/content/texts/<код>.json` — названия и описания фильмов.
3. Строка в `LANGUAGES` в `src/i18n/languages.ts`.

Ключи словаря типизированы по русскому словарю: опечатка в ключе ломает сборку, а у английского словаря TypeScript проверяет полноту.

## Покупки

Товары описаны в `src/core/products.ts`; их `id` должны совпадать с id в консоли Яндекс Игр. Цены и иконка валюты в игре не хранятся: по требованиям площадки они берутся из SDK.

| id | Что даёт | Тип |
|---|---|---|
| `starter_pack` | 500 жетонов, 5 билетов, 3 × 50/50, 2 × второй шанс | расходуемый, продаётся один раз |
| `tickets_5` | 5 билетов | расходуемый |
| `unlimited_1h`, `unlimited_24h` | ошибки не тратят билеты | расходуемый |
| `coins_300`, `coins_1000`, `coins_3000` | жетоны | расходуемый |
| `no_ads` | отключает полноэкранную рекламу | разовый |

Схема обработки: `purchase` → выдать → сохранить → `consume`. При запуске игра проверяет необработанные покупки, а метка выдачи в сохранении защищает от двойного начисления.
